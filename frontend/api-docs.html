Authentication

Send your CloudplusAI API key as a Bearer token. Keep your key on your server and never expose it in browser code.

Authorization: Bearer cpa_your_api_key

POST /api/v1/chat

POST/api/v1/chat

Send a message to the CloudplusAI model.

{ "message": "Explain Kubernetes in simple words" }

Response

{ "id": "chat_abc123", "object": "chat.completion", "model": "llama-3.1-8b-instant", "conversation_id": "...", "reply": "Kubernetes is a system for running and managing containers..." }

cURL

curl -X POST https://YOUR_DOMAIN/api/v1/chat \ -H "Authorization: Bearer cpa_your_api_key" \ -H "Content-Type: application/json" \ -d '{"message":"Hello CloudplusAI"}'

JavaScript

const response = await fetch("https://YOUR_DOMAIN/api/v1/chat", { method: "POST", headers: { "Authorization": "Bearer cpa_your_api_key", "Content-Type": "application/json" }, body: JSON.stringify({ message: "Hello CloudplusAI" }) }); const data = await response.json(); console.log(data.reply);

Python

import requests response = requests.post( "https://YOUR_DOMAIN/api/v1/chat", headers={"Authorization": "Bearer cpa_your_api_key"}, json={"message": "Hello CloudplusAI"} ) print(response.json()["reply"])

Try API

Security: API keys are credentials. Store them in environment variables or a server-side secret manager and revoke compromised keys immediately.
